Este projeto é um site de portfólio profissional desenvolvido com **HTML, CSS e JavaScript**, criado como atividade acadêmica e também como apresentação pessoal de projetos, habilidades e trajetória na área de tecnologia.

## Visão geral

O portfólio apresenta informações sobre minha formação, interesses profissionais, tecnologias utilizadas e projetos desenvolvidos. A proposta visual segue uma estética minimalista, escura e tecnológica, com foco em clareza, organização e identidade própria.

## Páginas do projeto

- `index.html` — Página inicial com apresentação profissional
- `projetos.html` — Página com projetos e filtro em JavaScript
- `contato.html` — Página de contato com redirecionamento para comunicação
- `sobre.html` — Página com informações sobre mim

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Recursos implementados

- Layout responsivo
- Navegação entre múltiplas páginas
- Uso de tags semânticas
- Cards de informações e projetos
- Alternância entre modo claro e modo escuro
